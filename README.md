# Dernier Rempart — survie zombie 3D

Jeu de survie zombie en 3e personne (three.js), mobile d'abord, **à jouer en paysage**. Modèles CC0 de Quaternius.

- Jouer : ouvrir `index.html` servi en HTTP (GitHub Pages : racine du dépôt, branche `main`) ; il redirige vers `3d/`.
- En local : `npm start` puis `http://localhost:3000/` (Internet requis : three.js vient du CDN jsdelivr).
- Tests : `npm test`.
- Détails, commandes et réglages : `3d/README.md`. Structure : `plan.md` et `3d/plan.md`. Suivi du projet : `RAPPORT.md`.

Une seule branche : `main`.
